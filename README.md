# 🍅 Pomodoro

Um timer Pomodoro feito atualmente com HTML, CSS e JavaScript, criado para ajudar no foco e na produtividade usando a famosa técnica Pomodoro.

---

## 🚀 Tecnologias Utilizadas até agora

- **HTML5**
- **CSS3**
- **JavaScript**
- **WAMP/XAMPP** (ambiente local)
  
---

## 📦 Como Instalar o Projeto

### 1️⃣ Clone o repositório

```bash
git clone https://github.com/Kinin08/Pomodoro
```
### 2️⃣ Entre na pasta

```bash
cd Pomodoro
```
### 3️⃣ Abra o projeto

```bash
index.html
```
### Pronto já está funcionando!
